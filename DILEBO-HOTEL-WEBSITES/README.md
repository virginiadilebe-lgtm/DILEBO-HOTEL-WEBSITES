# Dilebo Hotel Website

A responsive multi-page hotel website for Dilebo Hotel in Polokwane, Limpopo. The project showcases the hotel’s rooms, services, booking information, and contact details.

## Overview

This website includes a modern hospitality layout with a warm, elegant theme and navigation across multiple pages.

## Project Structure

- `index.html` — Home page
- `rooms.html` — Room options and pricing
- `bookings.html` — Booking form
- `about.html` — Hotel history and facilities
- `contact.html` — Contact information and message form
- `style.css` — Full website styling
- `images/` — Hotel and room images

## Features

- Responsive navigation menu
- Hotel landing page with hero image
- Room listings with pricing
- Booking enquiry form
- About page with hotel information
- Contact page with location and inquiry form
- Consistent styling across all pages

## Technologies Used

- HTML5
- CSS3
- Google Maps embed

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open any page such as `index.html` in your browser.
3. Optional: use a live preview extension for easier local viewing.
